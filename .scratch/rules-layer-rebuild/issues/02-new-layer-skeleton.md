# 02: 新层骨架与冻结声明

**What to build:** 规则层的新落点就位，旧规则文档被显式冻结。任何人（包括 agent）打开任何一份旧文档，第一眼看到「本文已冻结、只读，规则请到新层看」的声明与新层入口链接，不会再往冻结文档里加新规则。冻结不等于清空——旧文档内容此刻仍然可读可查。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 新层落点存在并各自写明用途：架构边界与依赖、业务不变量、验证入口、进度与计划（含归档子目录）、架构决策目录、术语词表。
- [ ] 每一份旧规则文档顶部都有显式冻结声明，含「已冻结」「只读」字样，并带一个可解析链接指向新层入口。
- [ ] 规则检查能报出「缺少冻结声明」的文档并指出文件；补上声明后判定为绿。
- [ ] 冻结声明不破坏文档原有结构，既有链接仍可解析。
- [ ] 仓库级 agent 约定中描述文档布局的那份文件已同步为新层布局。
- [ ] 归档目录与活跃文档物理分离：归档只放历史快照，活跃规则不写入归档。

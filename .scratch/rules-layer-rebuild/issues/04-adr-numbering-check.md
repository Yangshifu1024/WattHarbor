# 04: 架构决策目录编号与状态检查

**What to build:** 架构决策目录成为可信索引——编号连续、每份带状态标注。读者靠编号就能发现「中间缺了一篇」，不会因为编号跳号而误以为决策不存在。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 检查能报出：编号重号、编号断号、文件名与编号不一致、文件缺少状态标注。
- [ ] 现有两份 ADR 判定为绿。
- [ ] 状态取值集合固定且在说明中有定义（不是自由文本）。
- [ ] 检查在无数据库环境下运行。
- [ ] ADR 文件结构在检查与说明中一致：状态标注位置固定，可被机器解析。

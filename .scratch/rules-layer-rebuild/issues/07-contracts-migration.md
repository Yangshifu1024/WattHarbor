# 07: 业务不变量迁入 contracts 层

**What to build:** 业务与接口契约从旧文档迁到人读层的业务不变量层，旧文件删除。每条业务规则要么被某个检查守住，要么明说没有检查。规则的语义不变，只是换了承载方式与去掉了跨文档重复。

**Blocked by:** 02, 03, 06

**Status:** ready-for-agent

- [ ] 旧业务契约文档删除，新层业务不变量文档覆盖原有全部章节（方案与计量、支付启动与结束、在线卡与钱包、财务与审核、接口与权限、Webhook 发送契约、异步任务）。
- [ ] 每条规则条目带合法标记；无法断言的约束（意图、依赖方向、不可知后果）原地标注本条无对应检查。
- [ ] 跨文档重复内容已去重：同一规则只在唯一落点出现。
- [ ] 文档不再重述枚举取值列表，改为指向迁移 schema 的指针，可读性保留在解释里。
- [ ] 链接与标记检查在迁移后判定为绿。
- [ ] 资金与计量相关条目标注了「本批不做 Go 断言」，明确它们属于后续批次的断言化范围。

# 11: 重构路线图：剩余计划重建

**What to build:** 面向未来的重构工作从归档之外重建为一份精简计划，只留下真正待做的事。看计划的人一眼知道还有多少活、每件的验收是什么，不必翻历史流水。

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] 计划文档只包含未完成或明确计划中的工作，每项有目标、依赖与验收标准。
- [ ] 每项指向归档中的对应批次证据，或明确标注为新工作。
- [ ] 计划与归档之间的链接双向可达，链接检查判定为绿。
- [ ] 计划中不含已完成批次的流水。
- [ ] 计划里不重述已完成的批次流水，避免两份「进度」并存。

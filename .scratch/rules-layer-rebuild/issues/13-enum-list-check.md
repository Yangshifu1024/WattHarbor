# 13: 枚举列表不重述检查

**What to build:** 枚举取值不再在文档里各写一份。检查从迁移 schema 读出真相，判定文档中的列表是否与之一致；顺序敏感的枚举一律改为指针。取值变更时，文档不需要跟着改，也来不及改。

**Blocked by:** 07, 08, 09, 10, 11, 12

**Status:** ready-for-agent

- [ ] 检查从迁移初始化 SQL 解析枚举声明（列名与取值序），不硬编码任何取值。
- [ ] 判定口径：文档若重述某枚举的取值列表，该列表的取值集合与顺序必须与 schema 一致；被判定为顺序敏感的枚举不得出现列表，只能是指向 schema 的指针。
- [ ] 顺序敏感的枚举清单是显式的一节（人读层、带机器可解析格式），由人判定并可评审；清单缺失或格式错误时报红。
- [ ] 现存违规被清理为指向 schema 的指针，包含已知顺序相反的支付状态列表与设备状态全集列表。
- [ ] 违规时报红并指出文件、行与枚举列名。
- [ ] 判定范围为活跃文档；归档目录（历史快照）不在本检查范围，理由写进人读层说明而不是藏在实现里。
- [ ] 检查不需要数据库连接。

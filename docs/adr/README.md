# 架构决策记录

**类目**：架构决策。见 [规则层入口](../rules/README.md)。

本目录记录难以逆转的取舍：**难以逆转**、**无上下文时反直觉**、**源于真实权衡**三条齐全才收。只记录为什么，不记录规则本身——规则去 [架构边界与依赖](../rules/architecture.md) 与 [业务不变量](../rules/business-invariants.md) 写，这里留指针。

文件命名为 `NNNN-<slug>.md`，`NNNN` 从 `0001` 起连续编号，中间不跳号——编号连续本身就是索引，读者靠它发现缺失。目录里不另建迁移对照表，那类表会自己漂；追踪由 git 历史承担。

每份文件顶部写状态标注。

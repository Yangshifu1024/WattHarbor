# 充电状态页微信实机验收

- 目标：在微信实机核验充电状态和功率曲线。此前 H5 验证及 weapp 构建不能替代实机结果。
- 依赖：可访问测试环境的真机与小程序体验版本，以及有连续采样和缺失采样的订单。
- 验收：核对曲线可见、缺失段断开、手动刷新和切后台返回的行为；订单结束后停止轮询。记录设备、微信版本和实测结果，区分模拟数据与实机充电。

2026-11-28 用户端测试及微信登录模式的 `weapp` 构建通过，开发栈已验证充电停机与断线恢复。体验版和微信真机验收仍待执行。相关结果见[首发上线验收](../../first-release/spec.md#验收证据)。

## 四页改版与长列表验收

2026-11-28，开发 Compose 的 H5 连接实际站点、网关和账户接口。分别使用 320 × 700、390 × 844 两种视口，以 Chrome 进入首页、逐站查看列表并返回。页面使用统一的银灰、石墨黑和冰蓝配色。[四页实施截图](../../design/mobile-redesign-implemented.png) · [第 40 台设备截图](../../design/mobile-redesign-list-end.png)

| 核验项目 | 实际结果 |
| --- | --- |
| 夹具 | 新增 20 个带「列表验收」标记的站点，每站 40 台设备，每台 6 个端口。重复导入后仍为 800 台、4,800 个端口。刷新模拟上报后，真实 API 逐站返回 128 个可用端口、240 个总端口，全批可用 2,560 个。保留原有联调站。 |
| 首页分页及返回 | 第一页 20 站，加载更多后共 21 站。两种视口分别逐站检查，返回首页保留完整列表，无重复项。 |
| 站点列表 | 每站实际渲染 40 个不同设备编号。滚动后第 40 台的整行均能停在固定底栏上方，页面无横向溢出，浏览器控制台无业务错误。 |
| 设备与账户 | 进入夹具设备可见 6 个端口。原有联调站通过临时模拟器验证空闲端口、实际套餐、扫码取消保留选择、编号识别、开发账号登录、钱包和订单入口。 |
| 与样稿同尺寸对照 | 390 × 844 下，首页广告位为 (17, 69)、356 × 151，两个详情页广告为 (17, 69)、356 × 105。首页首行从 y=284 开始，站点首行 y=308，端口区 y=304，钱包为 (17, 153)、356 × 170。底栏在 y=780，高 64。以上坐标按 CSS 像素取整，与样稿相同。 |
| 回归 | 前端类型检查、120 项测试、H5 和微信构建通过。后端常规检查、公开契约、集成标签 vet 与真实双库站点测试通过。独立的全库串行复验中，网关补偿公平性测试 `TestSyncRetryPersistsFairnessAfterRestart` 预期读到 2 条到期回执，实际 1 条。 |

验收发现 19 位数字站点编号经浏览器解析后会发生舍入，导致重复列表键和详情跳错。公开响应保留数字字段并增加十进制字符串 `id_text`，首页与附近站点入口用该字符串去重或导航，已用相邻大整数和浏览器实际跳转复测。展示范围随站点数量、端口数量、真实资费、余额和订单状态变化。微信原生扫码、真实支付及设备回执仍待体验版与实机验收。

在仓库根目录执行以下命令可刷新[长列表夹具](../../../scripts/dev/seed-mobile-lists.sql)。脚本用独立厂商、夹具标记和专属设备编号识别记录，只在此开发库执行。每站 32 台设备写入最近上报时间，8 台模拟离线。可用端口随上报时间过期，验收实时数量前重新执行。

```sh
docker compose -f deploy/compose.dev.yaml exec -T mysql \
  sh -c 'MYSQL_PWD="$MYSQL_PASSWORD" exec mysql --protocol=TCP -h127.0.0.1 --default-character-set=utf8mb4 -u "$MYSQL_USER" central_db' \
  < scripts/dev/seed-mobile-lists.sql
```


### 浏览器批注复验

在 393 × 852 视口连接开发 Compose 复验首页和个人中心。[实测截图](../../design/mobile-profile-feedback.png)

- 首页末尾的定位和翻页按钮已移除。滚到末尾自动从 20 站续载至 21 站，进入最后一站再返回仍保留完整列表。最后一行底部在 y=766，固定导航从 y=788 开始。
- 个人中心直接展示全部八项服务。仅在开发登录模式下，资料区右侧提供「切换账号」，可选择常用账号或输入其他测试账号名称。
- 头像右侧展示当前账号已保存的昵称和已绑定的完整手机号。未设置昵称时可主动填写，微信端使用昵称输入框并在提交后保存；未绑定时可进入手机号授权页。
- 用独立开发账号保存昵称、绑定测试号码，切到另一账号时原昵称和号码均消失；切回后重新显示。确认解绑再返回个人中心后，号码已清除。测试号码仅用于本地模拟。

此次前端类型检查、120 项测试、H5 与微信构建通过。后端常规检查、公开契约、集成标签 vet、真实身份路由和全库串行集成测试通过，覆盖绑定、解绑、跨账号隔离及昵称保存。开发卷的默认脚本通过 TCP 获取 root 授权时仍返回 1045；本次经本地 socket 应用相同授权，再用现有测试库执行全套。微信原生昵称键盘及手机号授权弹窗仍待体验版真机验收。

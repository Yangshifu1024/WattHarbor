# 业务不变量

**类目**：业务不变量。人读层落点，见 [规则层入口](README.md)。

本文件承载计量、资金、权限与异步恢复的业务规则。写法约定：

- **这一类原则上不允许只以散文存在**。凡能写成断言的，散文处只留解释与指向检查的指针。
- 写不成断言的（意图、不可知后果、依赖方向）原地标注「本条无对应检查」。
- 文档不重述数据库枚举的取值列表，改为指向迁移 schema 的指针；取值真相源是 `backend/migrations/*/0001_init.sql` 的 ENUM 声明与 `backend/internal/domain/` 的 Go 常量。顺序有语义的枚举照抄列表必然漂，顺序无意义的纯集合才可以留在文档里。
- 资金与计量规则另有一批 Go 断言要走真实 MySQL，属后续批次，本批只标注归属不实现。

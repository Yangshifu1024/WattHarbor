# 进度与计划

**类目**：进度与计划。人读层落点，见 [规则层入口](README.md)。

本目录只放**仍然面向未来**的工作：目标、依赖、验收标准。规则本身不在这里写，规则去 [架构边界与依赖](../architecture.md)、[业务不变量](../business-invariants.md)、[验证入口](../verification.md) 与 [docs/adr/](../../adr/README.md)。

## 与归档的分界

- 计划：还没做完，或明确要做的下一批。
- [归档](archive/README.md)：已实施批次的流水与历史快照，只读。

两者物理分离在不同目录，不靠措辞提示。已完成的批次一旦验收通过就整批移入归档，不在计划里留摘要——留一份就会有两份「进度」并存，那本身就是一种漂移。

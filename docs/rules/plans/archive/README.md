# 归档

**只读目录。** 见 [进度与计划](../README.md)。

本目录只放历史快照：已实施批次的流水、取证结论与验收记录。归档里的内容**不随当前代码更新**，它的价值在于「当初为什么这么做」的证据可查。

- **活跃规则不写入归档。** 需要长期遵守的规则去 [规则层入口](../../README.md) 的对应落点写。
- **归档文件顶部标明它是历史快照、只读、不是活跃规则**，避免后来者把旧批次流水当成待办。
- 归档中的链接指向迁移后的新路径，指向已删除文件的链接一律更新，不留死链。

归档目录要不要排除在某条不变量的判定范围之外（例如按当时 schema 写成的枚举取值），由迁入归档的那几票决定，不在这里预先定口径。
